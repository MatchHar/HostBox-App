# Contributing

This repository accepts documentation corrections, translation improvements,
safe setup clarifications, and reproducible HostBox bug reports. It does not
accept or publish the private HostBox application source or deployment
implementation.

Before opening an issue or pull request:

1. Remove server addresses, SSH fingerprints, usernames, tokens, passwords,
   cookies, private keys, VINs, locations, database exports, Compose files, and
   raw production logs.
2. State the HostBox, iOS, server OS, and affected component versions without
   including credentials.
3. Separate observed behavior from expected behavior and provide minimal,
   redacted reproduction steps.
4. Use GitHub private vulnerability reporting for security issues.
5. Keep English, Simplified Chinese, and Traditional Chinese documents
   technically equivalent.

The repository checks reject App source, deployment scripts, credentials,
production addresses, signing material, and other files outside the public
documentation boundary.
