## 2026-08-30 — Initial documentation boundary

- Created the official HostBox product/support documentation repository.
- Documented setup, architecture, compatibility, operations, privacy, security,
  support, and third-party notices in three languages.
- Added CI protection against App source, deployment implementation, secrets,
  production addresses, signing material, binary artifacts, and stale links.
- Recorded the HostBox 1.22 public-release milestone as historical context while
  retaining Apple as the source of truth for the current public version.
